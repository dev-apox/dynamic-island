# Dynamic Island for Windows 🏝️💻

Bring fluid, Apple-inspired multitasking and contextual notifications directly to your Windows desktop. Designed with glassmorphism, responsive animations, and seamless background integration.

---

## ✨ Features

- **Contextual Expansions:** Expands dynamically for media playback, battery alerts, volume/brightness HUD, and notifications.
- **Modern UI:** Glassmorphism effects with fluent transitions.
- **Hardware Integration:** Real-time system monitoring (CPU/RAM load, media controls, battery state).
- **Lightweight & Fast:** Minimal background resource overhead.
- **Auto-Start Support:** Seamless launch on Windows startup with system tray minimization.

---

## 🚀 Quick Start (Installer)

1. Head over to the **[Releases](../../releases)** tab.
2. Download the latest `DynamicIsland-Setup.exe`.
3. Run the installer and follow the on-screen setup wizard.
4. Launch **Dynamic Island** from your desktop or start menu.
